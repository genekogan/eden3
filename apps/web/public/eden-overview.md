# Eden overview

Eden is a working prototype for persistent AI agents. A self-hosting operator can enable agent profiles, ongoing conversations, workspace files, memory, skills, media tools, schedules, sharing, and optional external channels.

This checkpoint is not production-ready, public-launch-ready, or migration-ready. Features depend on the operator's configuration and third-party services. Private agents, sessions, files, uploads, and unpublished creations are not public resources; sharing is explicit and revocable.

See `/llms-full.txt` for a longer product-oriented summary or the source repository documentation for setup and limitations.
